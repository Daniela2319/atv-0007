# 🚗 **Tabela de Veículos com HTML, CSS e JavaScript**

Este projeto exibe uma tabela de veículos criada dinamicamente usando HTML, CSS e JavaScript. A tabela inclui informações sobre marca, modelo, placa, descrição, cor e quilometragem.

##  **Tecnologias Utilizadas**
Este projeto foi desenvolvido utilizando as seguintes tecnologias:

* **HTML5**
* **CSS3**
* **JavaScript** 

## **Ferramentas de Desenvolvimento:**
  - Git e GitHub 
  - Visual Studio Code 
## 🔄 **Fluxo de Trabalho com HTML, CSS e JavaScript**
**1. HTML :**
Criação de uma estrutura básica para exibir bem-vindo e a descrição.


**2. CSS :**
Estilização da página e espaçamentos.
Definição de cores e estilo para melhorar a apresentação.

**3. JavaScript :**
Criação de um variáveis de veículos e com os dados dos veículos.
